# PSO2 Shape Studio

[English](README.md) | **日本語** | [한국어](README.ko.md) | [简体中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md)

PSO2 Shape Studioは、コスチューム体型補正AQM（`_sa.aqm`）を使って、PSO2および
PSO2:NGSのキャラクター体型を後から微調整するユーザー向けのWindowsデスクトップ
ツールです。Blenderを使わずに、モデルを確認しながら体型補正を適用・編集・保存できます。

> **現在のバージョン：** [1.3.1](https://github.com/gesori-pro/PSO2_Shape_Studio/releases/tag/v1.3.1)。
> 最新の自己完結型Windows x64ビルドは、リリースページからダウンロードできます。

## 機能

- `.aqp`、`.aqn`、`.ice`からPSO2モデルを開けます。
- 性別・種族別のキャラクタークリエイトデータ（`.fdp`、`.fnp`、`.fhp`、`.fcp`、
  `.mdp`、`.mnp`、`.mhp`、`.mcp`）と暗号化されていない派生ファイルを読み込み、
  体型とカラーを適用できます。男性と女性はそれぞれ専用の体型テーブルを使います。
- コスチュームの体型補正モーション（`_sa.aqm`）を読み込み・保存できます。
- `body_root`のYスケールで足裏の高さを0.500から1.200まで0.001刻みで調整し、
  ワールドY=0より下の交差部分を確認できる半透明の面付き床ガイドと比較できます。
- スケール、位置、回転をスライダーまたは数値入力で編集できます。数値欄ではマウス
  ホイールによる微調整が可能で、位置は0.001刻み、回転スライダーは中央付近で正確に
  0へスナップします。
- `Ctrl+Z`、`Ctrl+Y`、`Ctrl+Shift+Z`で体型編集を元に戻す、またはやり直すことが
  できます。
- オプション画面でゲームデータフォルダーとデフォルトのメイン／サブ肌カラーを設定し、
  標準の体型グループを表示または非表示にできます。
- AQNスケルトンを含むモデルを読み込むと、名前順の一覧から編集するボーンを左右ペア
  または単独ボーンのグループとして追加できます。標準と追加グループは1つのスクロール
  一覧にまとめて表示されます。
- 区切り線をドラッグしてサイドバーの幅を調整できます。幅は次回起動時に復元され、
  スクロール領域を使ってもファイル操作ボタンは常に表示されます。
- ローカルのPSO2ゲームフォルダーを指定し、データ構成を検証してモデル検索キャッシュを
  更新できます。
- 名前、ID、ファイル名、MD5でウェアモデルを検索し、ベースウェア、セットウェア、
  アウターウェア、旧仕様のコスチューム（トータルウェア）に絞り込めます。
- 選択したセットウェアに紐づくアウターウェアとインナーウェアを自動で読み込みます。
- カタログにデータがあるアイテムは、英語（Global）名と日本語名で検索できます。
- ローカルのゲームデータからタイプ1・タイプ2のスキンテクスチャーを選択できます。
- コスチュームを見やすくするため、ビューポートの背景色を8種類から選択できます。
- 対応するベースウェアとアウターウェアモデルに含まれる装飾パーツを表示・非表示にできます。
- アプリケーションの表示言語を英語（Global）、日本語、韓国語、簡体字中国語、
  繁体字中国語から選択できます。
- JSONファイルだけで表示言語を追加・上書きできます。詳しくは
  [ローカライズガイド](LOCALIZATION.md)を参照してください。

## 動作要件

- Windows x64
- ソースからビルドする場合は
  [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)
- モデル検索とテクスチャーの自動検索を使用する場合は、ローカルにインストールされた
  PSO2またはPSO2:NGS

展開済みのモデルファイルは、ゲームフォルダーを設定しなくても直接開けます。

## 基本的な使い方

1. PSO2 Shape Studioを起動します。
2. メイン画面またはオプション画面で、ゲームのインストールフォルダー、`pso2_bin`、
   または`pso2_bin/data`を選択します。
3. キャッシュを更新してウェアモデルを検索するか、展開済みのモデルファイルを直接
   開きます。
4. 必要に応じてキャラクターファイルまたは既存の`_sa.aqm`を読み込みます。
5. S/P/Rスライダーを編集するか、数値を直接入力します。オプション画面では標準
   グループを非表示にしたり、読み込んだモデルのボーンを追加したりできます。
   必要に応じて編集を元に戻すか、リセットします。
6. 編集結果を`_sa.aqm`ファイルとして保存します。ゲームに反映するには、
   次のセクションのリパック手順に従ってください。

## 保存した_sa.aqmをゲームに適用する

Shape Studioが保存する`_sa.aqm`は、1つの衣装だけに適用される体型補正
ファイルです。ゲームはこのファイルを単体では読み込まず、その衣装のICE
アーカイブ内にある元の`..._sa.aqm`エントリーを置き換えて初めて反映されます。
以下はコミュニティ製ICEツール
[Zamboni](https://github.com/Shadowth117/Zamboni)でリパックする手順です。

1. **元のエントリー名のまま保存します。** 先に衣装を読み込んでから
   *_sa.aqmを保存…*を押すと、保存ダイアログが読み込んだモデルに基づく正しい
   名前を提案します(例: `pl_rbd_201630_bw.aqp` →
   `pl_rbd_201630_bw_sa.aqm`)。この名前を変えないでください。別の名前で
   保存しても何も置き換えられません。
2. **衣装のゲームファイルの場所を確認します。** 検索結果にマウスを重ねると、
   その項目が指すICEアーカイブのフルパス(`pso2_bin/data/...`以下の32文字の
   ファイル名)が表示されます。読み込み済みモデルの一覧でも同じパスを
   ツールチップで確認できます。このファイルを`C:\work`のような短い作業
   フォルダーへコピーしてください — ゲームフォルダー内のファイルを直接
   編集してはいけません。
3. **コピーをZamboniで展開します。** コピーしたファイルをZamboniにドラッグ&
   ドロップすると展開されます。モデルデータは`group2`フォルダーにあり、元の
   `..._sa.aqm`もここに含まれます。
4. **エントリーを置き換えます。** `group2`内の`..._sa.aqm`を保存しておいた
   ファイルで上書きします。展開したフォルダー内にバックアップを置かないで
   ください — フォルダー内のすべてのファイルがそのまま再パックされます。
5. **リパックします。** 展開したフォルダーをZamboniで再パックし、インストール
   前に出力ファイル名が元の32文字の名前になっているか確認してください
   (必要なら名前を変更します)。作業パスが長すぎるとリパックが黙って失敗する
   ことがあるため、手順2の短いフォルダーが重要です。
6. **インストールします。** オリジナルを自動でバックアップ・復元できる
   [PSO2NGS Mod Manager](https://github.com/KizKizz/pso2_mod_manager)などの
   モッドマネージャーの使用を推奨します。手動でインストールする場合は、元の
   ゲームファイルを自分でバックアップしてから、リパックしたアーカイブで
   上書きしてください。

補足:

- 補正はリパックしたその衣装にのみ適用されます。
- ゲームのアップデートで元のファイルに戻ることがあります。その場合はモッドを
  再インストールしてください。
- インストール前に、リパックしたICEをShape Studioで開いて結果を確認できます。
- ゲームファイルの改変は自己責任で行ってください。

## カメラ操作

| 入力 | 操作 |
| --- | --- |
| 左または右ドラッグ | キャラクターを回転 |
| `Ctrl` + ドラッグ | カメラを上下に移動 |
| マウスホイール | ズームイン・ズームアウト |
| ホイールクリック | 視点をリセット |

## ソースからのビルド

サブモジュールを含めてリポジトリをクローンします。

```powershell
git clone --recurse-submodules https://github.com/gesori-pro/PSO2_Shape_Studio.git
cd PSO2_Shape_Studio
```

サブモジュールなしでクローンした場合は、別途初期化します。

```powershell
git submodule update --init --recursive
```

x64のRelease構成をビルドしてテストします。

```powershell
dotnet build Pso2ShapeStudio.sln -c Release -p:Platform=x64
dotnet test Pso2ShapeStudio.sln -c Release -p:Platform=x64
```

ソースからアプリケーションを実行します。

```powershell
dotnet run --project src/App/Pso2ShapeStudio.App.csproj -c Release -p:Platform=x64
```

配布用パッケージをビルドします。

```powershell
./publish.ps1
```

このスクリプトは`src/App/Pso2ShapeStudio.App.csproj`からバージョンを読み取り、
テストを実行したうえで、自己完結型のアーカイブを`dist/`に作成します。

## ゲームデータとプライバシー

PSO2のゲームアセット、展開済みモデル、テクスチャー、キャラクターファイルは、
このリポジトリには含まれていません。本アプリケーションはローカルコンピューター上で
選択されたファイルを読み込み、ゲームデータをアップロードしません。

## 依存関係とクレジット

- [PSO2-Aqua-Library](https://github.com/Shadowth117/PSO2-Aqua-Library)は、
  PSO2形式とICEデータを扱うために必要なソース依存関係です。
- 内蔵されている英語・日本語のアイテム名テーブルは、PSO2NGS Mod Managerの
  アイテムデータから生成されています。
